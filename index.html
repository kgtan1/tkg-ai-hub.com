Scope 4: Developer "Recipes" & Code Snippets

Practical code gists for agent caching and CLI sandbox setup.

2 min implementation Level: Developer

Setting Up 12-Hour Prompt Caching

Configures extended cache lifetime so background agents maintain low-cost cached inputs between idle turns.

import openai

# Set 12-hour prompt cache TTL for background agent loops
response = openai.chat.completions.create(
    model="gpt-6.1-sol",
    messages=[{"role": "system", "content": long_system_prompt}],
    cache_control={"type": "ephemeral", "ttl_hours": 12}
)

Scope 6: Tech & AI Glossary

Essential terminology for AI developers and engineering leads.

1 min lookup Level: General & Beginner

Proactive Agents

AI systems (like Claude Duet) that execute background tasks, monitor apps, and brief users without waiting for a manual prompt.

Decision Models & APIs

Specialized model routing mechanisms (like OpenAI's Decisions API) that evaluate action confidence and direct tasks across agent ensembles.

12-Hour Prompt Caching

A server-side memory mechanism that preserves long prompt context across idle turns, dramatically lowering latency and API token costs for agents.
